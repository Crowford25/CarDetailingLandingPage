# NOIR Auto Detail

A standalone premium car-detailing landing-page prototype for portfolio presentation and Malaysian freelance prospects.

## Stack

Next.js (App Router), React, TypeScript, Tailwind CSS, and Lucide React.

## Experience

The single page presents services, adjustable vehicle-size package prices, an interactive paint-correction comparison, gallery lightbox, enquiry success state, accordion FAQ, smooth anchor navigation, responsive mobile menu, and WhatsApp conversion links. Imagery is served through `next/image` from Unsplash and configured in `next.config.ts`.

## Structure

- `app/` — route, global style system, metadata
- `public/` — project-local static assets when needed
- `PROJECT.md` / `PROGRESS.md` — project documentation
